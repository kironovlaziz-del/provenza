# Changelog

## 0.1.0 (unreleased)

First release. It has the same behaviour and the same bytes as the Python
SDK 0.1.

- `Agent.create`: enrollment with keys generated on the agent's side. The
  identity file uses the shared format (mode 600). Optional hybrid
  Ed25519 + ML-DSA-65 keys.
- `agent.tool`, `agent.call`, `check` / `record`, `delegate`, `withChain`.
  The SDK fails closed by default. Standalone mode writes a signed local
  audit log. Unrecorded actions become signed gaps.
  `recordMode: "background"` is available.
- Canonical form, hashes and signatures are byte-identical to the server's.
  Tests check them against vectors generated by the server, and against the
  real server.
- Gateway settings: OpenAI-compatible LLM gateway and MCP.
- `provenza/auto`: the global fetch's direct calls to AI providers become
  governed egress actions, decided by the server against the AI domain
  catalog. A refusal is a 403 that provider SDKs do not retry. Prompts are
  never recorded.
- `provenza/integrations/langchain`: `governTool` and `governTools`, with
  `@langchain/core` as an optional peer dependency.
